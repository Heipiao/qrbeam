# QRBeam App Store screenshot concept v1

Upload-ready format: iPhone 6.5-inch portrait, 1284 × 2778 px, PNG without alpha.

The upload-ready localized files are in `6.5-inch-1284x2778/`. The original
1320 × 2868 design canvases remain in this directory as editable source renders.

The three-screen narrative is intentionally ordered as:

1. Use case — file transfer when devices cannot share a network.
2. Mechanism — animated QR frames travel optically from screen to camera.
3. Trust — no account or file upload; integrity is checked locally.

Chinese and English are separate localized sets. Open `index.html` with query parameters such as `?lang=zh&page=1` or `?lang=en&page=3`.

The generated `assets/optical-data-field.png` is a background texture only. All product UI, typography, icons, QR motifs, and copy are deterministic HTML/CSS so the screenshot text stays accurate.
